# AI 功能

Sakura Player 的「AI 歌词翻译」可以为当前歌词生成翻译、音译及逐字对齐内容，支持流式预览、补齐缺失与断点续译。先在 **设置 → AI 集成 → AI 模型配置** 中添加并启用文本模型，再进入全屏播放器使用。

## 功能与入口

| 功能                             | 入口                                 | 处理内容                                       | 所需配置                               |
| -------------------------------- | ------------------------------------ | ---------------------------------------------- | -------------------------------------- |
| AI 歌词翻译                      | 全屏播放器歌词右侧的语言图标         | 生成翻译、音译，并映射到现有歌词时间轴         | 启用一个 AI 模型                       |
| [本地歌词对齐](/lyric-alignment) | 全屏播放器歌词右侧的「算法智能对齐」 | 将已有翻译与音译关联到逐字主歌词，保留现有文本 | 音译开箱即用；翻译首次需下载或校验模型 |
| [MCP 接口](/mcp)                 | 设置 → AI 集成 → MCP                 | 让外部 AI 客户端搜索曲库、查询队列并控制播放   | 开启 MCP，并在客户端配置地址与连接密钥 |

AI 歌词翻译使用你配置的模型服务。本地歌词对齐由播放器自带的 Rust 工作进程计算，无需 Python 或模型 API Key；MCP 则把播放工具提供给外部客户端。三者分别配置，使用歌词翻译无需开启 MCP。

## 配置 AI 模型

1. 打开 **设置 → AI 集成**，在 AI 模型配置中点击 **添加模型**
2. 填写下表中的字段，按需调整思考等级
3. 点击 **测试连接**，确认地址、模型与密钥可用；测试可以取消
4. 保存配置，将需要使用的模型设为当前启用模型

| 字段     | 填写方式                                                                         |
| -------- | -------------------------------------------------------------------------------- |
| 配置名称 | 用于区分多个配置的显示名称，可自行命名                                           |
| 接口协议 | 按服务选择 `OpenAI Compatible` 或 `Anthropic`                                    |
| API 地址 | 服务提供的 API 根地址，例如 `https://api.example.com/v1`，保留服务要求的路径前缀 |
| 模型 ID  | 服务实际支持的模型标识，不是配置名称                                             |
| API Key  | 对应服务的密钥；编辑已保存配置时留空可保留原密钥                                 |

播放器会根据协议在 API 地址后追加 `/chat/completions` 或 `/messages`，因此不要把完整请求端点重复填入根地址。地址只接受 `http://` 或 `https://`，不能包含账号、查询参数或 `#` 片段。

可保存多个模型配置并切换当前模型。连接测试只确认一次文本请求可用，歌词生成还要求服务支持对应协议的 SSE 流式文本响应。

### 思考等级

`OpenAI Compatible` 配置支持 **服务默认、none、minimal、low、medium、high、xhigh、max**。选择 **服务默认** 时不发送思考等级参数；其他选项是否可用由具体模型与服务决定。`Anthropic` 配置不使用此选项。

如果服务提示不支持所选思考等级，编辑模型并改为服务默认或该服务支持的等级。较高等级通常需要更多时间和 token。

## 生成歌词翻译与音译

1. 播放一首已有歌词的歌曲，进入全屏播放器
2. 将鼠标移到歌词区域，点击右侧语言图标打开 **AI 歌词翻译**；沉浸模式下需先退出沉浸模式
3. 选择生成方式、生成内容，以及需要新译文时的目标语言
4. 点击 **开始生成**，查看逐行流式预览与处理进度
5. 全部待处理行完成并通过校验后，核对结果，点击 **应用所选内容**

没有主歌词或歌词仍在加载时无法开始。这里生成的是主歌词的辅助内容，不从音频识别歌词，也不重建主歌词的时间轴。

### 四类生成内容

| 项目     | 作用                                             |
| -------- | ------------------------------------------------ |
| 翻译     | 生成逐行译文                                     |
| 音译     | 生成以拉丁字母表示的读音，如日语罗马音           |
| 逐字音译 | 将音译片段关联到主歌词字词，供逐词显示与高亮使用 |
| 逐字翻译 | 将译文片段关联到主歌词字词，供逐字翻译高亮使用   |

打开弹窗时，缺失或不完整的项目会默认勾选，界面显示每类内容已有的行数。未勾选的辅助轨道保持原样。

在 **补齐缺失** 模式中，单独勾选逐字项会优先对齐已有文本，没有对应文本时才生成文本。例如，已有满意的译文、只想补时间映射时，可只勾选 **逐字翻译**。

译文目标语言支持 **简体中文、繁体中文、英语、日语、韩语**。仅对齐完整的已有译文时，不需要重新选择翻译语言；音译遵循原文读音。

逐字项目沿用主歌词字词的时间范围。只有行时间的主歌词会沿用整行范围，不能由此获得从音频提取的精确逐字时间。

### 两种生成方式

| 方式                 | 行为                                         | 适用情况                       |
| -------------------- | -------------------------------------------- | ------------------------------ |
| 补齐缺失（保留已有） | 复用已有内容，仅处理所选项目缺失或不完整的行 | 补上缺失译文、音译或逐字对齐   |
| 从头完整生成         | 从主歌词重新生成所选项目，替换对应文本与对齐 | 想更换译文语言，或重做已有结果 |

补齐模式不会把已有完整译文统一改成新语言。需要整首重新翻译时，选择 **从头完整生成** 并勾选翻译。

::: warning 重新生成逐行文本
从头完整生成翻译或音译时，如果没有同时勾选对应逐字项，其旧逐字对齐会被清除。需要同步更新文本与时间映射时，请把两项一起勾选
:::

## 取消、失败与续译

生成过程中可点击 **取消生成**。取消或失败后，已通过校验的完整行保留在当前弹窗中，可点击 **继续生成** 或 **从失败处继续**，只处理剩余行。输出截断、缺行、字段或字词范围无效时，界面会显示相应原因；可定位的校验错误会标出歌词行号。

- **继续生成 / 从失败处继续**：复用已完成行，并把失败原因作为反馈用于后续请求
- **重新生成**：重新运行当前选择的生成计划
- **关闭弹窗、切换歌曲、更新歌词，或更改语言、生成内容、生成方式**：清除当前进度，需要重新开始

续译进度只在当前弹窗会话内保留，不支持关闭播放器后恢复。生成未完整完成时不能应用，预览或取消均不会改动当前歌词。

## 应用、显示与保存

点击 **应用所选内容** 后，播放器一次更新所选辅助轨道，开启对应显示选项，并同步桌面歌词、灵动岛和任务栏歌词窗口。主歌词原文与时间轴保留。

在 **设置 → 歌词设置** 中可调整翻译、音译、逐词音译和 **逐字翻译高亮** 的显示。关闭逐字翻译高亮后，译文按整行显示。

::: tip 应用后仍需保存
应用只更新当前歌词，不会自动写入音乐标签或歌词文件。想保留结果，请打开歌词右侧的 **复制歌词**，在 **保存完整歌词** 中选择保存目标
:::

| 保存目标  | 条件与行为                                                                            |
| --------- | ------------------------------------------------------------------------------------- |
| 音乐标签  | 仅支持有本地文件路径的独立歌曲，不支持 CUE 分轨；保存原歌词格式及翻译、音译等辅助数据 |
| LRC 文件  | 本地独立歌曲保存为音频旁的同名文件；其他歌曲另存为。已有同名文件会被覆盖              |
| TTML 文件 | 当前主歌词须为 TTML，且已启用并配置本地 TTML 歌词库；保存至该库，命中已有文件时覆盖   |

点击 **预览更改** 可按所选目标查看保存前后的差异；需要另存为的 LRC 会在保存时选择路径，预览阶段尚未比较目标文件。完整保存不受上方用于复制的歌词行与过滤项影响。

**音乐标签** 中的辅助轨道和符合条件的 **TTML 文件** 可完整保留逐字译文。LRC 保留主歌词的逐字时间，普通译文副行按行导出，并通过 Sakura 扩展标签保存逐字译文和跨词音译范围，供本播放器重新读取。其他播放器对辅助轨道或扩展数据的支持不同，显示效果可能不同。

## 数据与凭据

- 只有点击测试或开始、继续生成时，才向配置的模型地址发起相应请求
- 歌词生成发送歌曲名称、歌手、待处理的歌词文本或字词，以及任务所需的已有翻译、音译；续译还会附带有限的错误反馈
- 不发送音频、封面、本地文件路径或原始时间戳；逐字任务返回的字词映射在本地换算为时间
- API Key 由主进程通过系统安全存储加密保存在本机，设置界面只显示是否已保存；安全存储不可用时拒绝保存或复用密钥，Linux 的 `basic_text` 后端也不被接受
- 请求由本机直接发往你配置的服务。服务方的数据保留规则、可用额度与计费方式由其自行规定，测试和生成均可能产生用量

只希望处理已有文本且无需调用配置的文本模型时，可使用 [本地歌词对齐](/lyric-alignment)。音译无需下载模型；翻译在首次下载或校验模型后离线运行。

## 常见问题

| 现象                               | 处理方式                                                        |
| ---------------------------------- | --------------------------------------------------------------- |
| 提示先启用模型                     | 在 AI 集成中保存配置并启用，再重新打开歌词翻译弹窗              |
| 连接测试成功，生成失败             | 确认服务支持 SSE 流式响应，检查协议、模型、额度及界面显示的错误 |
| 所选内容已完整，不能开始           | 切换为从头完整生成，或选择仍有缺失的项目                        |
| 新语言没有覆盖已有译文             | 补齐模式保留已有内容；整首改译需从头完整生成                    |
| 提示模型输出校验失败或达到输出上限 | 保持弹窗与任务选项不变，从失败处继续；也可调整模型配置后重试    |
| 应用按钮不可用                     | 等待全部待处理行完成；若歌曲或歌词已更新，重新开始任务          |
| 重新打开歌曲后结果丢失             | 应用后还需显式保存到音乐标签或歌词文件                          |

若要通过外部 AI 客户端搜索歌曲、查看队列或控制播放，请继续阅读 [MCP 接口](/mcp)。
