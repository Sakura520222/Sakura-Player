# Windows 7 / 8 / 8.1 Compatibility

The current repository uses Electron 43 and does not support Windows 7, 8, or 8.1. [Electron's official notice](https://www.electronjs.org/blog/windows-7-to-8-1-deprecation-notice) explains that support ended with Electron 23.

OS patches, VC++ runtimes, or TLS changes cannot make this Sakura Player version compatible with those systems. Use a package matching your architecture on Windows 10/11; see [Download](/en/download).

This project has no verified Windows 7 release branch. Older releases are not a compatibility guarantee. For launch failures on a supported system, include the OS version, architecture, installation form, and error logs; see [Debugging](/en/troubleshooting/debug).
