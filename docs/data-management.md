# 数据、缓存与备份

## 设置备份与恢复

在 **设置 → 常规设置 → 备份与重置** 中，可导出设置 JSON，或导入播放器导出的设置备份。恢复会覆盖当前主进程与界面设置，并在确认后重启应用。

设置备份不包含音乐文件、音乐库、歌单、播放历史、封面与歌曲缓存，也不包含单独存储的服务凭据或本地对齐模型。不能用一个设置 JSON 代替完整的数据迁移。

## 数据位置

| 系统 / 形式    | 默认用户数据目录                               |
| -------------- | ---------------------------------------------- |
| Windows 安装版 | `%APPDATA%\Sakura Player\`                     |
| Windows 便携版 | exe 同目录的 `SakuraPlayerData\`               |
| macOS          | `~/Library/Application Support/Sakura Player/` |
| Linux          | `${XDG_CONFIG_HOME:-~/.config}/Sakura Player/` |

自定义数据集中在该目录的 `app-data/` 下：

```text
app-data/
├── config/        设置、媒体源、Last.fm、AI 模型等配置
├── database/      library.db：曲库、歌单及其他本地记录
├── cache/         封面、歌手图、背景、歌曲缓存（可配置缓存位置）
├── logs/          应用与 native 日志
├── plugins/       插件脚本、数据与日志
└── runtimes/      本地歌词翻译对齐模型与就绪标记
```

本地音乐库索引和歌单不包含音频文件本身。完整迁移前退出播放器，备份实际用户数据目录以及原音乐目录；不要在应用仍写入数据库时只复制单个 `library.db`。系统安全存储保护的凭据复制到另一台设备后可能需要重新登录或输入。

## 歌曲缓存

**设置 → 本地与缓存 → 歌曲缓存** 可启用在线歌曲缓存，并单独控制媒体源歌曲是否缓存。默认关闭；开启后可设置容量上限，`0` 表示不限制。预载和交叉过渡可能在确认后启用这些选项，见 [播放控制](/playback)。

缓存用于加快播放，不等同于[音乐下载](/music-downloads)，不应作为永久保存歌曲的方式。

## 文件缓存与数据库缓存

同一设置页分别提供文件缓存管理与数据库管理，可检查占用并清理对应内容。封面 / 图片 / 歌曲文件与数据库缓存是不同目标，清理前确认界面列出的分类。

## 对齐模型

本地对齐的 Rust 工作进程随播放器提供，用户数据目录只保存模型和就绪标记，路径为 `app-data/runtimes/lyric-alignment/`。模型准备完成后可离线使用，音译无需下载模型。

在[对齐弹窗](/lyric-alignment#模型下载与移除)点击 **下载或校验模型**，仅下载缺失或损坏的文件，验证完整性并通过原生推理后即可使用。

使用 **移除模型** 清理本功能的模型目录；普通图片或歌曲缓存清理不会移除模型。模型使用中或维护中不能移除。完整备份可包含上述目录，设置 JSON 不包含这些文件。

## 重置与完整清理

**重置设置** 恢复配置默认值。当前 **清除全部数据** 操作会清理歌单、相关界面存储并重置设置，它并不等同于删除整个用户数据目录；不要把它当作对所有独立凭据、日志、数据库记录或模型文件的完整擦除。

确需完整重置时，先退出应用并备份，再确认实际数据目录后手动清理。便携版和安装版位置不同，原音乐文件夹也不应作为应用数据目录删除。排错和日志位置见 [调试指南](/troubleshooting/debug)。
