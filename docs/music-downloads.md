# 音乐下载

本页介绍下载歌曲到本地。播放器安装包请前往 [下载 Sakura Player](/download)；播放时产生的临时歌曲缓存见 [数据管理](/data-management)。

## 开启与使用

1. 打开 **设置 → 下载配置**，开启下载功能并选择保存目录
2. 在支持下载的歌曲菜单或全屏播放页选择下载，可指定音质或跟随默认设置
3. 批量操作时选择歌曲后加入下载队列
4. 从侧边栏 **下载管理** 查看待下载、下载出错与已完成的任务

本地歌曲无需再次下载。不同平台、插件和媒体服务器可提供的下载入口不同，实际资源及权限由对应服务决定。

## 下载选项

| 选项         | 行为                                                    |
| ------------ | ------------------------------------------------------- |
| 音质         | 默认无损，可按任务选择；实际结果取决于音源提供的文件    |
| 复用播放链接 | 选择是否复用播放地址下载；独立下载地址仍受服务规则限制  |
| 文件命名     | 曲名、歌手 - 曲名、曲名 - 歌手                          |
| 文件夹分类   | 不分类、按歌手、按歌手与专辑                            |
| 同名文件     | 默认自动重命名，也可选择覆盖或跳过                      |
| 写入内容     | 可选内嵌封面、元信息与歌词，以及另存同名 LRC、完整 TTML |
| LRC 格式     | 逐行 LRC 或增强 LRC，默认增强 LRC                       |

媒体源下载使用服务器的原始文件下载入口，可能需要额外的下载权限。下载不会上报为实际播放；仅下载或预载不应产生服务器的听歌打卡。

## 管理任务

- **待下载**：显示排队中与下载中的任务，可取消
- **下载出错**：包含失败、取消或中断的任务，可按当前可用操作重试
- **已完成**：可播放已下载歌曲、打开所在文件夹
- **标签写入失败，文件已保存**：音频下载已经完成，封面、歌词或标签处理未全部成功

**移除** 和 **清空已完成** 清理任务记录；后者也会清除已结束的出错记录，不删除已下载文件。**删除文件** 是另一项需要确认的操作，会永久删除磁盘文件。

播放器会识别已排队的同曲同音质任务及仍存在的已下载文件，避免重复加入。服务地址或账号变化后，媒体源下载按新的媒体身份区分。

## 常见问题

| 现象                 | 检查内容                                                   |
| -------------------- | ---------------------------------------------------------- |
| 看不到下载入口       | 是否开启下载、当前歌曲来源是否提供该入口                   |
| 解析失败或下载出错   | 网络、音源、账号权限、目标目录写入权限；查看任务错误后重试 |
| 下载音质与选择不一致 | 服务是否实际提供该音质，是否启用了复用播放链接             |
| 清空任务后文件仍在   | 清空记录会保留文件，删除文件需单独操作                     |
| 没有额外歌词文件     | 是否启用另存 LRC / TTML，且歌词来源是否提供对应内容        |
