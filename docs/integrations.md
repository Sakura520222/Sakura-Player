# 在线服务与听歌识曲

## 在线账号与页面

网易云登录后，可使用账号对应的喜欢歌单、收藏、每日推荐、私人 FM 与云盘等功能；可用内容取决于账号与平台接口返回。

QQ 音乐与酷狗账号在 **设置 → 其他设置 → 平台登录** 中管理。按界面提供的网页登录、扫码或手动 Cookie 方式操作；酷狗版本可在平台配置中选择。登录某个平台不代表其他平台的账号或权益可共用。

[歌曲高潮查询](/playback#歌曲高潮)会复用已有的网易云、酷狗登录会话及酷狗版本配置，不需要另行登录。获取开关、火焰按钮与无标注时的处理见播放指南。

搜索还支持[独立音源插件](/plugins/source#independent)。内置平台、插件与自建[媒体源](/streaming)分别管理来源与权限。

## 听歌识曲

顶部搜索区域的 **听歌识曲** 可识别系统声音或麦克风收音。

1. 点击听歌识曲，选择 **系统声音** 或 **麦克风**
2. 点击 **开始识别**，默认采集约 8 秒；期间可取消
3. 等待生成音频指纹并匹配，查看返回的歌曲候选
4. 可直接播放候选，或跳转搜索寻找对应歌曲

系统声音采集由 Windows / Linux 原生模块提供；原生采集不可用时，麦克风可走浏览器采集路径，需系统授予麦克风权限。界面会根据本机能力显示可用来源。识别期间播放器会暂停自身播放，结束或取消后按会话状态恢复。

音频指纹在本地生成，匹配请求将指纹与片段时长发送给网易云识曲接口。它需要网络，不能作为离线识曲或歌词语音转写使用，也不使用 AI 模型配置中的 API Key。

未识别到歌曲时，可改用更清晰的片段、检查收音设备与音量后重试；匹配服务不可用时检查网络。不要在不希望被处理的通话或私人音频上启动采集。

## Last.fm

在 **设置 → 网络与服务 → Last.fm** 中：

1. 开启 Last.fm 并点击 **连接账号**
2. 在浏览器完成授权，返回播放器等待显示已连接账号
3. 按需启用播放记录提交、正在播放与喜欢同步

授权等待可取消；断开连接会清除本地保存的 Last.fm 凭据。开启相关选项后，曲名、歌手及播放活动会发送给 Last.fm。本地[统计页](/library#播放历史与统计)与 Last.fm 历史独立。

Last.fm 会话密钥优先使用系统 `safeStorage` 加密；当前实现仍会在安全存储不可用时记录警告并退回 Base64，Base64 不等同于加密。流媒体密码和 AI 模型密钥采用不同策略，见 [隐私政策](/privacy)。

网易云听歌打卡单独位于 **设置 → 播放设置 → 听歌打卡**，默认关闭，可按界面选择上报方式。它不等同于本地播放统计，也不承诺平台一定计入听歌量。

## 系统媒体控制与 Discord

**设置 → 网络与服务** 中可控制系统媒体会话与 Discord RPC：

- 系统媒体控制对接 Windows SMTC、Linux MPRIS、macOS Now Playing
- Discord 状态默认关闭，可选择是否在暂停时展示及活动显示方式
- 当前 Fork 的 Discord RPC 暂时沿用上游 Application ID 与资源，开启后可能显示上游身份

Windows 任务栏悬停封面预览在 **设置 → 常规设置** 中控制；歌词窗口样式见 [歌词功能](/lyrics)。

## 网络代理与外部控制

**设置 → 网络与服务 → 网络代理** 支持关闭代理或手动配置 HTTP、HTTPS、SOCKS5 的主机与端口，并提供测试。请求是否成功仍取决于目标服务与代理可达性。

外部 HTTP 与 WebSocket 接口位于 **设置 → 网络与服务 → 外部 API**；MCP 位于 **设置 → AI 集成 → MCP**，各自拥有独立开关。连接与能力见 [HTTP API](/api)、[WebSocket API](/socket)、[MCP](/mcp)。
