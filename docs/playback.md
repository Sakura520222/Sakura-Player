# 播放控制与音效

## 播放队列与音质

播放器支持列表循环、单曲循环与随机播放，可查看队列并调整顺序。搜索结果的播放行为可在 **设置 → 播放设置 → 播放控制** 中选择只播放当前歌曲或将搜索结果加入队列。

**设置 → 播放设置 → 播放音源** 提供默认音质和试听选项。在线音质受音源、账号权限与歌曲实际资源限制，选择更高档位不会把低音质文件转换为无损。

## 歌曲高潮

**设置 → 播放设置 → 播放控制 → 获取歌曲高潮** 默认开启。歌曲加载完成后，播放器会查询网易云的副歌标注或酷狗的高潮标注，复用已有的平台登录会话及酷狗标准版 / 概念版配置，无需单独配置服务。

获取到标注后，进度条会显示金色的高潮区间。点击播放栏的 **火焰按钮** 跳转到高潮起点，普通、浮动和全屏播放器均可使用；暂停时跳转会保持暂停。有多段标注时，按钮优先跳到后续区间，没有后续区间时返回第一段。色带仅展示区间，调整进度仍使用原有的进度条拖动方式。

- **网易云与酷狗歌曲**：优先按原平台歌曲 ID 或 Hash 查询；没有有效标注或请求失败时，尝试匹配另一平台的版本
- **本地、QQ 音乐与流媒体歌曲**：按曲名和歌手搜索，再结合专辑与时长筛选匹配版本；无法可靠匹配时不显示高潮区间
- **插件来源歌曲**：暂不参与内置平台的高潮查询
- **重试与缓存**：有效标注会暂存在内存中，减少重复请求，退出播放器后不保留；没有标注或获取失败时，再次点击火焰按钮可重试

高潮查询需要网络，并依赖平台的标注覆盖率，不保证每首歌都有结果。持续失败时，可检查网络和[平台登录状态](/integrations#在线账号与页面)。当前不提供本地音频分析，也不需要配置 AI 模型或下载音频来识别高潮。

查询会向相应平台发送歌曲 ID / Hash，或曲名与歌手搜索词，不会读取或上传音频文件。关闭 **获取歌曲高潮** 后，播放器停止发起新的高潮查询，并隐藏色带与火焰按钮。

## 播放栏更多菜单

| 入口         | 功能                                                              |
| ------------ | ----------------------------------------------------------------- |
| 音频输出信息 | 查看实际设备、独占状态、音源与输出采样率、位深、重采样及 DSP 状态 |
| 均衡器       | 调整 10 频段均衡、前级增益，或选择预设                            |
| 播放速度     | 调整 0.5–2 倍速、-12 到 12 半音；开启音调同步可在变速时保持原音调 |
| AB 循环      | 设置起点 A 和终点 B，且 B 晚于 A 后启用片段循环                   |
| 定时关闭     | 设置 1–180 分钟倒计时，可选择等待当前歌曲结束后再停止             |

这些工具在常规播放栏与全屏播放器的更多菜单中均可打开。定时功能用于停止播放，不是系统关机计划。

## 渐入渐出与歌曲交叉过渡

在 **设置 → 播放设置** 中可分别配置：

- **渐入渐出**：启停时的音量平滑，时长可选 100–600 毫秒
- **预载下一首歌曲**：提前缓存并解码下一曲，可能增加网络与磁盘占用
- **交叉过渡**：在曲尾交接下一首；交接倾向可选保守、标准、积极

启用预载或交叉过渡时，若歌曲缓存和流媒体缓存未开启，播放器会请求确认并一并开启所需缓存。选择交叉过渡也会启用预载；关闭预载会将过渡方式改为无过渡。

过渡依赖下一曲成功准备，受播放模式、音源和缓存状态影响。歌曲无法提前准备时，不应期待每次切换都产生交叉效果。缓存大小与清理见 [数据管理](/data-management)。

## 输出设备

在 **设置 → 播放设置 → 输出设备** 中选择设备，按需开启切换设备时暂停、音量同步等选项。Windows 提供 WASAPI 独占输出；实际是否成功独占、是否发生重采样，请以 **音频输出信息** 中的当前值为准。

音量均衡、均衡器、变速变调会参与音频处理。若要核对当前输出，查看实际状态比只检查偏好开关更准确。

## 歌词、频谱与快捷键

- 点击播放栏封面展开全屏播放器，可切换歌词、队列与沉浸显示
- 音乐频谱在 **设置 → 播放设置 → 音乐频谱** 中开启
- 快捷键在 **设置 → 快捷键配置** 中分别配置应用内与全局作用域；重复或被系统占用的组合键会提示冲突
- 桌面歌词、灵动岛与 Windows 任务栏歌词的配置见 [歌词功能](/lyrics)

Linux 的全局快捷键和悬浮窗口可能受桌面环境限制，见 [Wayland 兼容性](/troubleshooting/wayland)。
