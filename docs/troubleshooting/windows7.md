# Windows 7 / 8 / 8.1 兼容性

当前仓库使用 Electron 43，Windows 7 / 8 / 8.1 不受支持。[Electron 官方说明](https://www.electronjs.org/blog/windows-7-to-8-1-deprecation-notice)从 Electron 23 起已移除这些系统支持。

安装系统补丁、VC++ 运行库或修改 TLS 设置，不能让当前 Sakura Player 成为兼容旧系统的版本。请在 Windows 10 / 11 上使用与设备架构匹配的安装包，见 [下载](/download)。

本项目没有经验证的 Windows 7 发行分支，不应把旧发行包当作兼容保证。若在受支持系统上遇到启动问题，请附上系统版本、架构、安装形式和错误日志，参考 [调试指南](/troubleshooting/debug)。
