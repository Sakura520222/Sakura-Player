# 歌词功能

## 格式与来源

支持 **TTML、LYS、QRC、KRC、YRC、LRC、ASS、SRT**。逐字高亮需要歌词本身包含逐字时间；只有行时间的歌词不会因切换显示开关而获得精确逐字时间。

| 来源         | 内容                                            |
| ------------ | ----------------------------------------------- |
| 外部歌词     | 本地音频旁的歌词文件、媒体服务器提供的歌词      |
| 内嵌歌词     | 从音频标签读取的正文与受支持的辅助轨道          |
| 在线歌词     | 网易云、QQ 音乐、酷狗的歌曲歌词及可用翻译、音译 |
| 插件歌词     | 插件按已声明能力提供的内容                      |
| 本地 TTML 库 | 用户配置目录中匹配到的 TTML                     |

在 **设置 → 歌词设置 → 歌词内容** 中调整来源偏好、音源顺序、格式顺序、插件歌词优先和智能优选。自动模式会结合已有歌词与格式优先级选择；指定平台优先与「自身来源」有不同的回退行为，流媒体自身来源指服务器返回的歌词。

## 在线与本地 TTML

- **在线 TTML**：在歌词设置的 TTML 区域开启，地址模板需包含 `%p`（平台）与 `%s`（歌曲 ID）；AMLL TTML DB 覆盖网易云与 QQ 音乐关联
- **本地 TTML 库**：开启并选择 `.ttml` 目录，按文件中的歌曲 ID 或元信息匹配，同一文件可关联多个网易云 / QQ 音乐 ID
- 本地匹配用于优先采用自己的歌词版本；在线 TTML 是否被选中还受来源偏好和格式排序影响

## 显示与字体

**设置 → 歌词设置** 提供物理引擎与 AMLL 引擎、主歌词字号、自适应字号、翻译字号及跟随主歌词、翻译与音译、逐字译文高亮、逐词音译、注音、和声识别与歌词排除等选项。部分动画或布局设置仅对当前引擎显示。

在 **设置 → 外观设置 → 字体** 中可分别配置界面、主歌词、中日文 / 韩文 / 拉丁字形，以及外部歌词窗口的字体。歌词还支持 OpenCC 简繁、地区用字和部分日文字形转换。

全屏播放器歌词右侧提供偏移调整、AI 翻译、算法对齐与复制工具；歌词工具栏在沉浸模式下隐藏。点击歌词行可跳转到对应时间。

## AI 生成与本地对齐

已有主歌词需要补充翻译或音译时，使用 [AI 功能](/ai)。已有文本只想建立逐字时间映射时，也可使用无需模型 API Key 的 [本地歌词对齐](/lyric-alignment)。两者应用后均需显式保存才能写入文件。

## 复制、分享与保存

打开 **复制歌词** 后可勾选歌词行，选择是否包含翻译、音译、空行、歌名与歌手，再复制文本或导出歌词图片。**复制原文** 读取当前歌词正文。

下方的 **保存完整歌词** 独立保存整首内容，不受用于复制的行选择与过滤项影响：

| 目标     | 条件与覆盖行为                                                                 |
| -------- | ------------------------------------------------------------------------------ |
| 音乐标签 | 本地独立音频可写，CUE 分轨不可用；保留正文格式，并保存独立翻译、音译等辅助数据 |
| LRC      | 本地独立音频旁的同名文件，存在时覆盖；其他来源另存为                           |
| TTML     | 当前正文为 TTML，且本地 TTML 库已启用并配置目录；匹配到已有库文件时覆盖        |

**预览更改** 按目标对比保存前后内容；LRC 另存为的路径在保存时选择，预览阶段尚未读取该目标。保存后查看各目标的成功或失败反馈。

逐字正文使用增强 LRC 导出，译文在 LRC 中按行保存。需要保留逐字译文时选择音乐标签中的辅助轨道或符合条件的 TTML；跨词音译范围使用播放器扩展数据，其他播放器不一定支持。

## 外部歌词窗口

| 窗口       | 配置                                                   |
| ---------- | ------------------------------------------------------ |
| 桌面歌词   | 位置、字号、颜色、对齐、翻译、逐字显示、锁定与鼠标穿透 |
| 灵动岛     | 紧凑歌词窗口及其显示样式                               |
| 任务栏歌词 | Windows 任务栏内的原生歌词显示                         |

在 **设置 → 外部歌词** 分别调整样式，或通过播放栏、托盘等可用入口开关。Linux 窗口置顶、定位与鼠标穿透受桌面环境限制，见 [Wayland 兼容性](/troubleshooting/wayland)。
