# 歌词功能

## 格式与来源

支持 **TTML、LYS、QRC、KRC、YRC、LRC、ASS、SRT**。逐字高亮需要歌词本身包含逐字时间；只有行时间的歌词不会因切换显示开关而获得精确逐字时间。

| 来源         | 内容                                            |
| ------------ | ----------------------------------------------- |
| 外部歌词     | 本地音频旁的歌词文件、媒体服务器提供的歌词      |
| 内嵌歌词     | 从音频标签读取的正文与受支持的辅助轨道          |
| 在线歌词     | 网易云、QQ 音乐、酷狗的歌曲歌词及可用翻译、音译 |
| 插件歌词     | 插件按已声明能力提供的内容                      |
| 本地 TTML 库 | 用户配置目录中匹配到的 TTML                     |

在 **设置 → 歌词设置 → 歌词内容** 中调整来源偏好、音源顺序、格式顺序、插件歌词优先和智能优选。自动模式会结合已有歌词与格式优先级选择；指定平台优先与「自身来源」有不同的回退行为，流媒体自身来源指服务器返回的歌词。

## 在线与本地 TTML

- **在线 TTML**：在歌词设置的 TTML 区域开启，地址模板需包含 `%p`（平台）与 `%s`（歌曲 ID）。播放器可按网易云或 QQ 音乐 ID 查询；没有匹配到时，还可通过 AMLL TTML DB 按曲名和歌手搜索，再用时长等信息筛选候选
- **本地 TTML 库**：开启并选择 `.ttml` 目录，按文件中的歌曲 ID 或元信息匹配，同一文件可关联多个网易云 / QQ 音乐 ID
- 本地匹配用于优先采用自己的歌词版本；在线 TTML 是否被选中还受来源偏好和格式排序影响

## 手动匹配歌词

自动匹配选错了版本时，在全屏播放器的歌词工具栏点击 **匹配歌词**。弹窗会用当前曲名和歌手搜索，也可以修改关键词并切换网易云、QQ 音乐或酷狗。开启在线 TTML 后，可在 **TTML** 标签中搜索 AMLL TTML DB。

点击候选查看原文和格式。预览会随当前播放进度高亮歌词，并区分对唱行的位置，便于核对同名歌曲、现场版或翻唱版。确认后点 **使用此歌词**，播放器会记住该曲目的选择并优先使用。点击 **恢复自动匹配** 可清除这条记录。

## 显示与字体

**设置 → 歌词设置** 提供物理引擎与 AMLL 引擎、主歌词字号、自适应字号、翻译字号及跟随主歌词、翻译与音译、逐字译文高亮、逐词音译、注音、和声识别与歌词排除等选项。部分动画或布局设置仅对当前引擎显示。

在 **设置 → 外观设置 → 字体** 中可分别配置界面、主歌词、中日文 / 韩文 / 拉丁字形，以及外部歌词窗口的字体。歌词还支持 OpenCC 简繁、地区用字和部分日文字形转换。

全屏播放器歌词右侧提供偏移调整、AI 翻译、算法对齐与复制工具；歌词工具栏在沉浸模式下隐藏。点击歌词行可跳转到对应时间。

## AI 生成与本地对齐

已有主歌词需要补充翻译或音译时，使用 [AI 功能](/ai)。已有带行级时间的主歌词时，可用 [主歌词转逐字](/lyric-alignment#主歌词转逐字) 结合本地或已缓存的音频计算逐字时间。本地对齐也可将已有翻译或音译关联到逐字主歌词。

主歌词和翻译各需准备对应的 [本地模型](/lyric-alignment#模型下载与移除)，音译对齐可直接使用。应用结果后，仍需在「保存与导出歌词」中保存到文件。

## 复制、分享与保存

打开 **复制歌词** 后可勾选歌词行，选择是否包含翻译、音译、空行、歌名与歌手，再复制文本或导出歌词图片。**复制原文** 读取当前歌词正文。

下方的 **保存与导出歌词** 处理整首歌词，独立于上方用于复制和分享的勾选项。

| 目标                 | 保存内容与位置                                                                                                                               |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 嵌入 TTML 到音乐标签 | 将完整歌词写入可写的本地独立音频标签。CUE 分轨不可用                                                                                         |
| 完整 TTML            | 保留正文、翻译和音译的逐字时间。已启用并配置本地 TTML 库时保存到库中，可更新匹配的文件。否则在本地独立音频旁写入同名文件，其他曲目可选择位置 |
| 兼容格式             | 可选 LRC、增强 LRC（A2）、YRC、QRC 或 LYS。本地独立音频写到同目录，其他曲目可选择位置                                                        |

兼容格式将可用的翻译和音译按行写入同名的 `.tr.lrc` 和 `.roma.lrc`。LRC 保留行起点，A2 保留词起点，YRC 和 QRC 保留词的起止时间，LYS 还可保留声部。需要保留逐字翻译和跨词音译关联时，选择 **完整 TTML**，移动文件时带上同名的 `.sakura.json`（如果已生成）。

**预览更改** 会按保存目标比较已有内容。需要另选路径时，预览展示将要导出的内容，路径在保存时选择。弹窗也可清除当前翻译或音译，之后使用保存功能可将更改写入所选目标。

## 外部歌词窗口

| 窗口       | 配置                                                   |
| ---------- | ------------------------------------------------------ |
| 桌面歌词   | 位置、字号、颜色、对齐、翻译、逐字显示、锁定与鼠标穿透 |
| 灵动岛     | 紧凑歌词窗口及其显示样式                               |
| 任务栏歌词 | Windows 任务栏内的原生歌词显示                         |

在 **设置 → 外部歌词** 分别调整样式，或通过播放栏、托盘等可用入口开关。Linux 窗口置顶、定位与鼠标穿透受桌面环境限制，见 [Wayland 兼容性](/troubleshooting/wayland)。
