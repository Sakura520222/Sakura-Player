# 流媒体服务

除本地音乐与在线音源外，Sakura Player 还支持接入自建的流媒体服务器，直接访问你私有曲库。

## 支持的服务

| 类型            | 说明                                                                 |
| --------------- | -------------------------------------------------------------------- |
| **Subsonic 系** | Navidrome、OpenSubsonic、Airsonic、Gonic、LMS 等兼容 Subsonic 的服务 |
| **Jellyfin**    | 开源媒体服务器                                                       |
| **Emby**        | 媒体服务器                                                           |

> Subsonic 系服务共享同一套协议，差异仅体现在界面标签上。

## 添加服务器

1. 打开 **设置 → 媒体源配置**，确认媒体源开关已开启；
2. 新增一个服务器，选择类型（Subsonic / Jellyfin / Emby）；
3. 填写服务器地址、用户名与密码；
4. 可先测试连接再保存；第一台服务器会自动设为当前服务器，其他服务器可通过 **连接** 切换，连接后在侧边栏 **媒体源** 浏览歌曲、专辑、歌手与歌单。

支持配置**多个服务器**并切换当前服务器。编辑已保存配置时，密码留空可复用已有密码。

::: tip 凭据安全
服务器密码由主进程使用系统 `safeStorage` 加密保存。安全存储不可用，或 Linux 使用 `basic_text` 后端时，拒绝保存非空密码，不退回 Base64 明文。`accessToken` / `userId` 只在主进程会话中缓存，连接时重新获取，不作为持久化配置传给界面。
:::

## 同步、收藏与服务器身份

歌曲、专辑、歌手与歌单索引同步到本地 SQLite。新同步完成后统一发布；失败或中断会保留上一份完整快照，恢复连接后可重试，不会把半份结果当作完整曲库。

收藏操作以服务器响应为准，本地列表随后更新。服务器改名保留原媒体身份；地址、类型、用户名或密码变化会更新媒体身份，旧缓存与下载记录不会混作新账号的内容。

## 播放、歌词与下载

播放地址和鉴权由主进程处理；播放器界面使用不含访问凭据的媒体身份。封面同样经主进程代理读取。优先使用服务器歌词或按歌词设置匹配其他来源，见 [歌词功能](/lyrics)。

实际播放会驱动 Jellyfin / Emby 的开始、进度、停止会话，以及 Subsonic 的正在播放与听歌记录；下载和预载不会冒充播放。下载取原始文件，受服务器下载权限约束，见 [音乐下载](/music-downloads)。

## 常见问题

- **连接失败**：检查服务器地址是否包含正确的协议（`http://` / `https://`）与端口，以及账号密码是否正确。
- **歌曲无法播放**：确认服务器本身可正常转码 / 直链，并检查网络是否可达。
- **同步失败后仍看到旧内容**：这是保留上一份完整快照的行为；排查错误后重新同步。
- **无法保存密码**：启用系统密钥环或修复安全存储，无法解密时重新输入密码。
