# 曲库、歌单与统计

## 添加与扫描本地音乐

从侧边栏打开 **音乐库**，添加要扫描的文件夹。已有曲目时，可在页面的 **更多 → 目录管理** 中继续添加目录，添加后会开始扫描。

- 页面刷新按钮执行增量扫描；**更多 → 全量扫描** 重新扫描已配置的目录
- 扫描过程中显示进度，完成后可搜索歌曲，并按列表表头排序
- 从歌手、专辑和文件夹页面浏览同一曲库，歌曲无需复制到播放器的数据目录
- CUE 分轨使用原音频及分轨时间范围播放；保持 CUE 与其引用的音频路径有效

添加文件夹的入口在音乐库页面，设置中没有独立的「本地音乐」分类。首次进入已有目录的音乐库会自动扫描；文件发生变化后，可再次扫描更新索引。

## 标签与封面

本地曲目的菜单提供元信息编辑，可修改曲名、歌手、专辑、封面等内容。编辑会写入音频文件，请确认文件可写，并在批量修改前保留原文件备份。

CUE 分轨对应共享音频，不能按普通独立歌曲的方式写入每首的文件标签。修改标签与仅调整播放器的显示设置是两种不同操作。

歌词保存有独立的完整保存与差异预览流程，见 [歌词功能](/lyrics)。

## 我喜欢的音乐

**我喜欢的音乐** 分为本地与在线两个标签页。本地喜欢与音乐库关联；在线列表使用已登录网易云账号的喜欢歌单。媒体服务器的收藏在各自的[媒体源](/streaming)中管理。

**更多 → 复制到剪切板** 会将当前显示的列表复制为每行 `曲名 - 歌手`，遵循当前排序方向和搜索过滤。没有搜索结果时不会复制被过滤掉的歌曲。

需要批量处理时，从更多菜单进入 **批量管理**，按当前页面提供的操作选择曲目。

## 本地歌单与在线收藏

可创建本地歌单、修改名称与描述，通过歌曲菜单添加到歌单，并在歌单中移除曲目或删除歌单。本地歌单保存在播放器数据库中；删除歌单与删除磁盘上的音频文件是不同操作。

在线歌单、专辑和歌手收藏，以及网易云的每日推荐、私人 FM、云盘等入口，取决于登录状态与平台返回的数据。登录入口和平台差异见 [服务集成](/integrations)。独立音源插件通过[插件搜索](/plugins/source#musicsearch)提供自己的歌曲结果。

## 播放历史与统计

| 页面     | 内容                                                                 |
| -------- | -------------------------------------------------------------------- |
| 播放历史 | 查看播放器记录的历史曲目，继续播放                                   |
| 统计     | 曲库概览、聆听足迹热力图、播放时段、音质构成、最常听歌曲、专辑与歌手 |

统计页读取本地记录，聆听足迹展示近 90 天的数据，最常听榜单各展示 10 项。它不会自动拉取第三方账号的全部历史，也不等同于 [Last.fm 或网易云听歌打卡](/integrations)。

## 备份范围

设置中的 **备份设置** 只导出配置，不能备份音乐库、歌单、播放历史或原始音频。迁移前请阅读 [数据管理](/data-management)，分别保留应用数据与音乐文件。
