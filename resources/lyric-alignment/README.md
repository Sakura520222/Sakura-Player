# 本地歌词对齐

全屏播放器歌词右侧的“算法智能对齐”入口将已有翻译、音译关联到主歌词时间轴。原来的 AI 生成入口和模型配置保持独立。

音译使用 Kuromoji（Apache-2.0，内含 IPADIC 词典）分词、WanaKana（MIT）转换读音，再通过全局编辑距离匹配现成音译。整词可横跨多个原文字词，例如“今”“日”共同对应 `kyou`。原有大小写、空白、标点均由原文本切片保留。主要面向日语罗马音，词典不支持或匹配分数不足时保留原行。

翻译使用 [SimAlign](https://github.com/cisnlp/simalign)（MIT）的多语言 BERT / IterMax。中文分词使用运行时的 ICU `Intl.Segmenter`，无需另装 jieba。词索引映射回原词时间；跨语言重排和一对多映射合并成语义短语，不按译文长度制造时间。完整覆盖和匹配评分只是筛选条件，不保证翻译正确，应用前应检查预览。

## 安装与卸载

在对齐弹窗点击“安装环境”，播放器会自动下载便携 Python、创建虚拟环境、安装依赖、下载模型并执行推理验证。打开弹窗或点击对齐不会自动安装。安装显示分阶段进度，可取消或失败重试；关闭弹窗或主窗口后继续后台安装，重新打开可查看进度。环境维护期间关闭按钮会暂时隐藏主窗口，不修改原有关闭偏好；明确退出播放器会取消安装并等待清理。

点击“卸载环境”可移除本功能的 Python、虚拟环境、模型和缓存，对齐占用环境期间不能卸载。音译无需安装；未安装时取消勾选翻译即可使用音译对齐。

文件统一存放于 `{userData}/app-data/runtimes/lyric-alignment/`，不读取系统 Python，不修改 PATH，不使用全局 Python 包或 Hugging Face 缓存。安装未完成时不会发布可用标记，中断后的残留可重新安装或卸载。便携版整体移动后需重新安装虚拟环境。

## 固定资产与平台

- 便携解释器来自 [Python Standalone Builds](https://github.com/astral-sh/python-build-standalone/releases/tag/20261013)，固定 CPython 3.12.15，安装时校验长度和内置 SHA-256
- 覆盖 Windows、macOS、Linux 的 x64 / ARM64；Windows ARM64 使用 x64 解释器及依赖，需要系统支持 x64 应用
- macOS 使用 PyTorch 2.2.2 与 NumPy 1.26.4 兼容 Intel Mac，Windows / Linux 从 PyTorch 官方 CPU 索引安装 2.14.1，不下载 CUDA 依赖
- Windows 的 VC++ 运行库通过 `msvc-runtime` 安装到专用虚拟环境并按绝对路径加载，不要求用户另行安装系统组件
- 模型固定为 `google-bert/bert-base-multilingual-cased` 的 `3f076fdb1ab68d5b2880cb87a0886f315b8146f8` 版本，逐文件校验 SHA-256，采用 safetensors
- 下载遵循播放器网络代理配置，pip 使用官方索引、独立配置和无缓存安装
- 模型准备完成后，验证和对齐均离线执行；大文件最多四路分段写盘，服务器不支持分段时顺序下载，完成后统一校验，不在主进程缓存完整文件

## 行为与资源

- 只处理真实逐字主歌词，默认跳过已完整对齐和缺少辅助文本的轨道
- 勾选“重新对齐已有逐字翻译和音译”可重算所选辅助轨道，保留原文和主时间轴；未选项目及匹配不足的行继续使用原有对齐
- 开始前选择翻译或音译，计算后再勾选候选行；统计分别列出本次检查、匹配成功及保留已有对齐的数量
- 对齐入口和预览不显示鼠标悬浮提示
- 切歌、换源、更新歌词、关闭窗口或取消任务会使旧结果失效
- 同时只运行一个任务；每次任务独占 worker 和 Python 子进程，结束或取消后释放词典和模型
- 输入限制为 1,000 行、合计 64,000 个字符；Python 输出限制为 1 MiB
- 算法候选转换为现有 AI 歌词翻译使用的结果，复用同一套词内音译、辅助时间轴、显示开关、TTML 保存和窗口同步流程，无需保存文件即可更新显示，原文和主歌词时间戳保持不变
- 在模型加载或计算失败时，已成功的音译可单独应用；翻译原样保留
